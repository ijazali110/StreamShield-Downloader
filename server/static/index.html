FUTURE STUDIO FEATURE

Windows Desktop Companion

V2.2

Runs yt-dlp and FFmpeg on your Windows PC instead of the VPS. YouTube and supported clear media use your local internet connection and local disk.

  • Download and extract the ZIP.
  • Double-click INSTALL_AND_RUN.bat.
  • Paste a YouTube/media URL directly in Shield Stream Desktop.
  • Choose Best / 1080p / 720p / 480p / MP3 and download locally.

No Shield Stream free-plan duration, resolution or file-size caps are applied by the desktop app. Source/site restrictions and local disk/network limits still apply.

Chrome / Edge Extension

DEEP SCAN

Companion extension detects standard non-DRM HLS, DASH, video and audio streams exposed during playback.

Extension-assisted deep scan is off. Normal VPS URL analysis remains unchanged.

  1. Extract the ZIP.
  2. Open chrome://extensions.
  3. Enable Developer mode → Load unpacked.
  4. Select the extracted extension folder.
  5. Play media → open Shield Stream Companion → Power scan 30s.

Deep scan capabilities

Quick scanAvailable

Checks video/source elements, frames, player configs and browser-visible resource URLs.

Power scan 30sAvailable

Uses Chromium Network debugging to observe standard clear media requests while playback continues.

On-video Download menuAvailable

Shows detected qualities over compatible HTML5 players and sends the selected stream to the local desktop app.

DRM / license endpointsNot supported

Widevine, PlayReady, FairPlay and protected-license flows remain blocked/ignored.

ANDROID + CHROME

Install Shield Stream

  1. Open this dashboard in Chrome on Android.
  2. Tap Install app, or Chrome's menu → Add to Home screen / Install app.
  3. Open the installed app and sign in with your workspace password.

Installation and Android's Share menu depend on Chrome/device support. Copy and paste works without installation.

Download a supported source

  1. Copy a public or authorized non-DRM video/page URL.
  2. Paste it in Sources, or use the site's Share → Shield Stream option if available.
  3. Tap Analyze, pick quality and audio, then Add to queue.
  4. Open Downloads. Once completed, tap Save to device. Chrome usually saves it to your phone's Downloads folder.
