STREAMFORGE UNIVERSAL VIDEO DOWNLOADER V2.1
FULL PROJECT SUMMARY / HANDOFF DOCUMENT
============================================================

Project Name:
StreamForge Universal Video Downloader

Latest Version:
V2.1 – On-Video Quality Toggle

Platform:
Windows Desktop App + Chromium Browser Extension

Main Purpose:
A Windows desktop video downloader that can download media from normal URLs, YouTube/yt-dlp compatible websites, direct media links, HLS/DASH streams, and embedded webpage media detected through a Chromium browser extension.

The tool is designed for standard non-DRM media that the browser or website legitimately exposes. It is not intended to bypass DRM, paywalls, encrypted access controls, Widevine, PlayReady, FairPlay, or similar protection systems.


============================================================
1. MAIN WORKFLOW
============================================================

Typical workflow:

Play Video
→ On-video Download button appears
→ Choose quality
→ Stream is sent to StreamForge desktop app
→ Preview
→ Download


============================================================
2. YOUTUBE + NORMAL URL DOWNLOADING
============================================================

The desktop app supports pasted URLs.

Main backend technologies:
- yt-dlp
- FFmpeg
- imageio-ffmpeg
- PySide6

Supported source types include:
- YouTube / yt-dlp compatible websites
- Normal webpages
- Direct MP4 URLs
- Direct WebM URLs
- Direct audio URLs
- HLS / .m3u8
- DASH / .mpd
- Standard embedded webpage media


============================================================
3. EMBEDDED WEB VIDEO DETECTION
============================================================

The Chrome extension is designed to detect media inside webpages.

It is not limited to only <video> tags.

Detection can include:
- <video> elements
- <source> elements
- Nested iframes
- Accessible embedded players
- Open Shadow DOM
- Common media-related data attributes
- Dynamically loaded media
- Network responses
- Fetch/XHR traffic
- HLS manifests
- DASH manifests
- Direct video/audio responses
- Extensionless media responses
- Small media/player/config responses
- Standard media URLs found in WebSocket text messages


============================================================
4. IDM-STYLE ON-VIDEO DOWNLOAD BUTTON
============================================================

V2.1 introduced an IDM-style download button directly over a playing HTML5 video.

Example:

↓ Download

When clicked, a quality menu can appear over the player.

Possible options:

Best Available
2160p
1440p
1080p
720p
480p
360p
Audio

The extension prefers qualities that were actually detected for the current player/media.

The browser itself does not blindly download the media. The selected stream/quality is sent to the StreamForge desktop app.


============================================================
5. SMART STREAM GROUPING
============================================================

A single webpage/player can generate many media requests.

Instead of showing dozens of duplicate items, StreamForge groups related variants under the same logical video.

Example:

Same Video
├── 1080p
├── 720p
├── 480p
└── Audio

Fresh capture information can update the existing result instead of always creating a duplicate card.


============================================================
6. QUALITY / MANIFEST DISCOVERY
============================================================

The project can inspect HLS and DASH manifests.

It can identify information such as:
- Resolution
- Bitrate
- FPS
- Language hints
- Separate audio/video tracks

For DASH or other split-stream formats:

Video Track
+
Audio Track
→ FFmpeg Merge
→ Final MP4


============================================================
7. PREVIEW BEFORE DOWNLOAD
============================================================

Each result can be previewed before downloading.

Preview logic includes:
- Built-in Qt preview for compatible/local media
- ffplay for streams requiring headers or special handling
- FFmpeg short compatibility preview fallback if needed

V2.0.1 contained an important preview reliability fix which is preserved in V2.1.


============================================================
8. POWER SCAN 30s
============================================================

The Chrome extension includes scan modes such as:

Quick Scan
Power Scan 30s

Recommended use for difficult embedded players:

1. Open the webpage.
2. Start video playback.
3. Run Quick Scan.
4. If needed, run Power Scan 30s.
5. Keep playback active during the scan.
6. Let the extension observe network activity.
7. Select the strongest detected candidate.


============================================================
9. VERIFIED STREAMS
============================================================

The extension evaluates detected media candidates.

Stronger and more reliable network/media candidates can be marked or prioritized as VERIFIED.

The on-video quality menu should prefer verified streams when possible.


============================================================
10. EXPIRING / SIGNED URL HANDLING
============================================================

Some websites use temporary CDN links such as URLs containing:

?token=...
?expires=...

If a stream becomes stale or expired:

403 / 404 / expired token
→ Refresh from Chrome
→ Extension scans the source tab again
→ Fresh stream candidate is returned
→ Desktop result is updated

The app should not keep retrying a clearly expired URL forever.


============================================================
11. REFRESH FROM CHROME
============================================================

The desktop app can keep a relationship with the originating browser tab.

If a captured URL expires, a "Refresh from Chrome" action can request a fresh capture from the original browser page.


============================================================
12. RELIABLE / RESUMABLE DOWNLOADS
============================================================

The download system is designed to support:
- .part files
- Resume
- yt-dlp continuation
- HLS/DASH fragment downloading
- Retry / fallback behavior

Speed modes can include:

Normal
Fast
Maximum

Maximum mode can optionally use aria2c when suitable.

18. DUPLICATE PROTECTION

23. LOCAL DESKTOP BRIDGE
============================================================

The browser extension communicates with the desktop app through a local bridge.

Known local endpoint:

127.0.0.1:8765

The bridge is intended to bind only to localhost and not expose a public internet-facing server.


============================================================
24. SECURITY / PRIVACY DESIGN
============================================================

Important protections include:
- Localhost-only bridge
- Random per-process pairing token
- Reject normal webpage origins from talking directly to the bridge
- URL scheme validation
- Payload-size limits
- Avoid storing browser cookies in desktop history
- Avoid storing Authorization headers in history
- Remove/clear temporary tab media candidate state
- Allow history to be disabled


============================================================
25. FALSE-POSITIVE FILTERING
============================================================

Deep capture should not treat every network request as valid video.

Filtering is intended to reject or deprioritize:
- Tiny media fragments when not useful
- HTML pages
- Error pages
- 403/404 responses
- DRM/license endpoints
- Obviously invalid media responses

This reduces cases where an HTML/error response is mistakenly saved as a video file.


============================================================
26. DRM / ACCESS-CONTROL BOUNDARY
============================================================

The project deliberately does NOT attempt to bypass:

- Widevine
- PlayReady
- FairPlay
- DRM license systems
- Paywalls
- Encrypted access-control systems

The intended scope is standard non-DRM media that the browser legitimately exposes and that the user is authorized to download.

============================================================

1. Open the target webpage.
2. Start playing the video.
3. Check for the on-video Download button.

7. Prefer VERIFIED media candidates.

9. Send it to StreamForge.
